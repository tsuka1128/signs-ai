# Signs AI 全体品質監査プロンプト集（Fable 5向け）

SaaSとしての完成度を上げるための観点別レビュープロンプト。**観点ごとに別セッションで**実行し、リポジトリアクセス＋`CLAUDE.md`＋（デザイン/UXは）実画面スクショを渡すこと。

## 使い方（3原則）
1. **観点別に分割・別セッションで**回す（文脈を混ぜない）。「全部良くして」の一発は浅くなるので禁止。
2. **Fable 5の主戦場＝① デザイン ② UX ③ 価値**（審美眼・全体判断）。④正しさ ⑤技術も価値あるがOpusでも可。
3. 各パスは**「発見→優先度付きバックログ」まで**。実装はいきなり大改修せず、小さなPR＋レビューで消化する。

## 共通ヘッダー（各プロンプトの先頭に貼る）

```
あなたは Signs AI の共同創業者格のシニアプロダクトデザイナー兼スタッフエンジニアとして、辛口かつ具体的にレビューする。
プロダクト: 組織の体温を可視化するBtoB SaaS。KPI×従業員アンケートをClaude APIで分析し経営者に示唆を提案。ブランドは「組織に体温を」。
技術: Next.js(App Router)/TypeScript/Tailwind/Supabase(PostgreSQL+RLS)/Vercel。
デザイン言語: アクセント teal(#38B2AC)＋slate基調、Noto Sans JP、rounded-2xl/3xlカード、状態は天気アイコン(晴/曇/雨)。
ロール: super_admin / admin / executive / manager / player / partner。
制約(CLAUDE.md): RLSは get_my_company_id() 必須 / DB変更はmigrationのみ / recorded_month は KPI=YYYY-MM-01・サーベイ=YYYY-MM / トースト成功=緑・失敗=赤。
対応済み(再提案不要): 読込速度改善(index/font/dynamic import/メモ化/未使用依存削除)、認証トリガー修正、招待フロー、ホーム刷新。
出力要件: 発見ごとに「該当ファイル:行 / 重大度(高中低) / なぜ問題か / 具体的な直し方(できれば before→after) / 工数感」。最後に優先度順トップ10。抽象論禁止、必ずこのリポジトリの実物に基づくこと。
```

## ① デザイン/ビジュアル完成度（Fable 5の主戦場）

```
[共通ヘッダー]
視覚デザインの一貫性と美しさを監査せよ。まず『Signs AIらしい洗練』のデザイン原則を5箇条で定義し、それに照らして差分を出す。
対象: tailwind.config のトークン、共通UI(Badge/Card/Loading/WeatherIcon/EmptyState等)、主要画面(ホーム/部署マネジメント/設定/ダッシュボード各セクション/ログイン・登録)。可能なら実画面スクショも判断材料にする。
観点: タイポ階層(font-blackの多用は妥当か)、余白・グリッドのリズムと規則性、色の過不足、コンポーネント間の不整合(角丸/影/境界線/パディングの揺れ)、空状態・ローディング・エラーの見栄え、視線誘導、モーションの一貫性。
「今すぐ効く見た目の底上げトップ10」を before→after 付きで。
```

## 実行後の分担
- 出たバックログは **Opus（このコードベースに精通）が実装可能性・整合性の観点でレビュー** → 小さなPR＋レビューで消化。
- **Supabase障害中**は、⑤のレジリエンス(タイムアウト/再試行)や①④のデザイン/コピーなど**静的に直せるもの**から着手可。

## 付録：スクショ撮影リスト・命名規則

全ページを撮る必要はない。**代表画面 × 状態 × ロール × 画面幅**の組み合わせで枚数対効果を最大化する。不整合は「状態違い・幅違い」で最も見つかる。

### 保存先
`docs/reviews/screenshots/`（このファイルと同じ場所。**gitignore済み**＝実データが映るPNGはcommitしない。ローカルからは普通に参照可）

### 命名規則
```
<画面>__<状態/ロール>__<desktop|mobile>.png
```
例：
```
home__admin__desktop.png
home__player__desktop.png
home__empty__mobile.png
dept__populated__desktop.png
settings-members__desktop.png
register__invite-banner__desktop.png
form__empty__mobile.png
```

### Tier 1（必須・毎日見られる中核）
- `/` ホーム … **admin と player の両方**（ロールで出し分けが変わる）
- ダッシュボード各セクション：`?sec=report / matrix / kpi / org / survey / action / semantic`（データありの状態）
- `/dept` 部署マネジメント
- `/settings` … 代表2〜3枚（会社/KPI/メンバー招待）
- `/kpi` KPI入力
- `/onboarding`（新規作成モード）＋ `/register`・`/login`（招待バナー有/無）
- `/form` アンケート回答（一般社員が触る唯一の画面）

### Tier 2（余力があれば）
- `/voice-check`、`/history`、`/monthly-focus`、`/hr-strategy`（Pro）
- `/admin`・`/admin/billing`
- `/marketing`（公開LP＝別デザイン言語。やるなら独立パス扱い）

### 基本スキップ
`/docs/*`、`/privacy`・`/terms`、`/proposal`（監査価値が低い）

### 状態バリエーション（各代表画面で優先）
1. **空状態**（データ未入力の初回）… Supabase不安定時でも撮りやすく、初回体験の質に直結
2. **データあり**（通常）
3. **ローディング/エラー**（永久スピナー等の異常系含む）
4. **モバイル幅**（375px程度）を主要3〜4画面だけでも

### 補足
- Fable 5がリモート/クラウドでローカルディスクを見られない場合は、チャットに画像を直接貼るか、その回だけ一時的にcommitする。
- スクショで拾えない細部（デザイントークン・共通UIの実装）はコードも併読させれば補完できる（①のプロンプトで `tailwind.config` と `components/ui`, `components/dashboard` を対象と明記済み）。
