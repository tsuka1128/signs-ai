# 仕様書：部署マネジメント /dept のIA整理（アクションハブ統合）

> ステータス：設計・仕様（実装前）
> 対象：`src/app/dept/page.tsx`
> 目的：提案・アクション系が4ブロックに散らばって「まとまりが無い」状態を、**「状況 → 方針 → アクション」の3ブロック**に再構成して見やすくする。あわせて低スコア警告バナーを撤去しAI提案に吸収する。

## 重要な前提（厳守）
- **これは見た目（情報設計）の再配置であり、ロジックは変えない。** 既存のJSXブロックを**移動・グルーピング**するだけ。判断（採用/完了/キープ/不採用）・履歴トグル・採用フロー・匿名ガード・AI要約再生成などの**ハンドラと条件分岐はそのまま保持**する。
- DB変更・API変更・migration なし。

## 現状（散らばり）
提案・アクション系が4箇所：要注意シグナル（低スコア警告）/ 経営方針インボックス / 部署に届いたアクション提案 / AIからの今月提案 / アクションプラン（今月）。状況系（回答状況・AI要約・体温プロフィール・設問別）も間に挟まり散漫。

## 新しいページ構成（描画順）

### A. ヘッダー
- 部署切替セレクタ（上位ロールのみ・現状維持）

### B. 状況（Sense）— 状況系を上に集約
1. 今月のボイスチェック回答状況バナー（＋推移グラフ accordion）
2. 体温プロフィール（レーダー・5テーマ）
3. 今月の設問別スコア（全社比ペアバー）
4. ボイスチェックの声（AI要約）
- **要注意シグナルの単独バナーは撤去**（下記参照）

### C. 方針（Direction）
- 経営方針インボックス（今月の方針・過去の方針）＝現状の中身を移設

### D. アクション（Act）ハブ ← 目玉。提案＋実行を1セクションに集約
1セクション「アクション」の中に2グループ：
- **対応待ちの提案**
  - **経営層から届いた提案**（`execActions` ＋ `execActionHistory` トグル）＝旧「部署に届いたアクション提案」の中身をそのまま
  - **AIからの今月提案**（`actionPlans` の `source==='ai_proposed' && status==='proposed'`）＝旧「AIからの今月提案」の中身をそのまま
  - 2つは**出所が分かる小見出し/バッジ**で区別（「経営層」「AI」）。判断ボタン等は各既存フローを維持
- **実行中／今月のアクションプラン**（`actionPlans` の `status!=='proposed'`）＝旧「アクションプラン（今月）」の中身

## 低スコア警告の扱い（ご要望）
- 旧「🚨 要注意シグナル」の **「N つの設問でスコアが 3.0 を下回っています」バナーは撤去**。
- 代わりに **「AIからの今月提案」ブロックの導入文**として表示：
  - 例：「今月、◯◯・◯◯ の設問が 3.0 を下回りました。以下の提案で対処しましょう。」
  - `questionScores.filter(avg<3.0)` から設問名を出す。3名未満（匿名ガード未通過）のときは出さない。
- もう一方のシグナル（**前月比の急降下アラート**＝`signals` の critical）は撤去せず、**状況ブロック内**（回答状況バナー付近または体温プロフィール付近）に小さく配置する（重要なので残す）。

## スコープ
| 項目 | 対象 |
|---|---|
| 提案2＋実行1を「アクション」ハブに集約（出所バッジで区別） | ✅ |
| 状況系を上に・方針を中・アクションを下に再配置（3ブロック） | ✅ |
| 低スコア警告バナー撤去 → AI提案の導入文へ | ✅ |
| 急降下アラートは状況ブロックへ移設（残す） | ✅ |
| 判断/採用/履歴/匿名ガード/再生成などのロジック | ❌ 変更しない（移動のみ） |
| DB/API/migration | ❌ なし |

## レビュー観点（Claude）
- **ロジック非破壊**：判断（完了/キープ/不採用）、AI提案の採用/見送り、履歴トグル、AI要約再生成のハンドラが移動後も全て動くか（onClick・state・条件が欠落していないか）。
- JSXの入れ子・閉じタグ崩れがないか（大きな移動なので要注意。`npm run build` 通過必須）。
- 匿名ガード（3名未満非表示）・headcount=0ガード・各空状態が維持されているか。
- 低スコア導入文が `questionScores` の当月・匿名ガード通過時のみ出るか（0件時・ガード未通過時に出さない）。
- 上位ロール/manager で出し分けている箇所（部署切替・判断ボタン等）が移動で壊れていないか。
- 体温プロフィール／設問別スコア（全社比）など直近追加分が保持されているか。
