# SignsAI Core Philosophy & Theoretical Foundation

このドキュメントは、SignsAIの設計思想、およびその理論的根拠となる外部データ・フレームワークとの整合性と独自価値を定義します。開発、マーケティング、および将来の意思決定における一貫性を担保するための最上位指針です。

---

## 1. 外部環境と理論的背景

SignsAIの設計は、単一の理論ではなく、以下の理論的支柱に基づいています。

### 1-1. Gallup「State of the Global Workplace」— エンゲージメントの経済的インパクト

Gallup社が発表した最新のレポート（2024年版）が指摘する課題は、SignsAIが解決しようとしている問題の核心と完全に一致しています。

- **エンゲージメントの危機**: 全世界のエンゲージメントは21%まで低下し、全世界で約4,380億ドルの生産性損失を生んでいる。
- **マネージャーの影響力**: チームエンゲージメントの分散の70%はマネージャーに起因しており、マネージャー自身のエンゲージメント低下が組織全体の最大のリスクとなっている。
- **経済的インパクト**: エンゲージメントを70%まで引き上げることができれば、世界GDPの約9%（9.6兆ドル）の経済効果が見込める。

SignsAIは、この**「Gallupが警鐘を鳴らしている課題そのものを、SaaS化した解決策」**です。

> ※ 数値は Gallup「State of the Global Workplace 2024 Report」に基づきます。最新レポートが発行された際は適宜更新してください。

---

### 1-2. Balanced Scorecard（Kaplan & Norton, 1992）— 非財務指標をKPIと並列に扱う根拠

Kaplan & Norton が提唱した Balanced Scorecard（BSC）は、「財務指標だけでは組織の健全性と将来性を正確に測れない」という洞察から生まれました。BSCは財務・顧客・内部プロセス・学習と成長の4視点を組み合わせることで、組織の実態を多面的に評価します。

SignsAIにおける「KPI（財務・業績指標）」と「体温（エンゲージメント・感情指標）」を同一ダッシュボードで並列管理する設計は、**BSCの問題意識（単一指標だけでは組織を測れない）に基づき、最小構成の2軸統合を実現したもの**です。BSCの4視点（財務・顧客・内部プロセス・学習と成長）すべてをカバーするものではなく、最も実務的な意思決定に効く2軸（業績と感情）に絞り込んでいます。

- **Gallupが「なぜエンゲージメントが重要か」を示し**
- **BScが「どの指標の組み合わせで組織を測るか」の構造を与える**

この2点によって、SignsAIの「数字（KPI）と感情（体温）の統合管理」という設計方針に理論的必然性が生まれます。

---

### 1-3. 心理的安全性（Amy Edmondson, 1999 / Google Project Aristotle, 2016）— 設計上の安全性担保の根拠

ハーバードビジネススクールのAmy Edmondsonは、「心理的安全性（Psychological Safety）」 —— チームメンバーが罰せられる恐れなく率直に発言できる環境 —— が、チームの学習行動と業績の最大の予測因子であることを実証しました。この知見は2016年のGoogle Project Aristotleでも再検証され、「最も生産性の高いチームの共通要素は心理的安全性である」と結論づけられています。

SignsAIは、この理論をプロダクト設計に直接実装しています。

| 設計上の判断 | 心理的安全性との対応 |
| :--- | :--- |
| アンケートの完全匿名化 | 「誰が何を言ったか」が特定されない環境の保証 |
| 3名未満での定性コメント非表示 | 少人数グループでの発言者特定リスクの排除 |
| AIによる声の抽象化（voiceTopics） | 生データを見せず傾向のみを提示することで発言者を保護 |

> ※ 3名閾値は **k-匿名性（k-anonymity, k=3）** の最小実装基準です。学術的なエンゲージメント調査（Gallup Q12等）では5名以上が推奨されており、本プロダクトでも回答者数が5名以上に達したグループでは、より高い匿名性が担保されます。3名は「**実用上の最小閾値**」であり、運用時はできる限り5名以上のグループ単位で分析することを推奨します。

**設計上のテンション解消：** SignsAIは「マネージャーが変革のレバー」（§ 1-1）と「マネージャーには生データを見せない」（§ 1-3）という、一見矛盾する2つの原則を同時に掲げています。これは矛盾ではなく **設計思想** です：

> マネージャーは **抽象化されたシグナル（AI分析・トピック抽出）** を受け取り、**個人ではなく構造（プロセス・配置・対話の場）** に介入する。

個人特定によるマイクロマネジメントを排し、組織システムへの介入によって全体最適を図る。これがSignsAIにおけるマネージャー支援の哲学です。

これらの制約は利便性とのトレードオフではなく、**心理的安全性を担保しなければ正直な回答が得られず、データ自体の信頼性が失われる**という理論的必然から生まれています。

### 1-4. 先行指標 vs 遅行指標（Leading / Lagging Indicators）— 「Signs（兆候）」の存在意義

経営管理において、指標は2種類に分類されます。

- **遅行指標（Lagging Indicators）**: 売上・KPI達成率・離職率など、**結果が出てから初めて確認できる**指標。
- **先行指標（Leading Indicators）**: エンゲージメント・体温・コミュニケーション頻度など、**結果が出る前に変化を捉えられる**指標。

遅行指標だけを管理する経営は、バックミラーを見ながら運転する行為と同義です。離職や業績悪化という「結果」は、エンゲージメントの低下という「兆候（Signs）」に数週間〜数ヶ月遅れて表れます。

SignsAIのプロダクト名「Signs（兆候）」は、この先行指標の概念に由来しています。

**現状の実装：** 毎月の体温スコアと KPI を同一画面で並列表示することで、両者の乖離・トレンド変化を視覚的に検知できる構造を提供しています。

**今後の拡張（次フェーズ予定）：**
- 時間ラグ相関の可視化（体温(t) → KPI(t+1, t+2)）
- 体温の急変検知に基づく予兆アラート機能
- 過去データから学習する離職リスクスコアの提示

これらにより、現状の「**並列管理**」から、真の意味での「**先行警報システム**」へと進化させていきます。

### 1-5. Human Capital ROI（Jac Fitz-enz, 2000）— 人件費を投資として捉える視点

Jac Fitz-enzが体系化した Human Capital ROI の思想は、「人件費をコストとして最小化するのではなく、投資として最大化するROIの視点で評価する」というものです。この考え方は、現代のピープルアナリティクス（People Analytics）の基盤となっています。

SignsAIの「体温×総人件費バブルチャート（LaborFinance画面）」は、この思想を実装したものです。

- **X軸 = 総人件費**: 投資額の可視化
- **Y軸 = 体温（エンゲージメント）**: 人的資本の健全性指標
- **カラー = ROI**: 投資対効果の可視化

この3軸の組み合わせにより、「どの部署が高い投資効率で健全に機能しているか」「どの部署が高コストにもかかわらず低エンゲージメントか」を一目で判断できます。

**実装上の注記：** 本プロダクトの「ROI」値は、Fitz-enz の正式な HCROI 式（`(Revenue − (OpEx − Compensation)) / Compensation`）の簡易版であり、現時点では **「KPI達成率 ÷ 人件費」による達成効率指標** として実装しています。今後、売上データの取り込みが進んだ段階で、より厳密な HCROI 算出に拡張予定です。Fitz-enz の**思想**（人件費＝投資）を実装している点は変わりませんが、**算出式そのものは簡易化されている**ことに留意してください。

### 1-6. 11問サーベイの設計根拠 — Q12 との差別化と独自設計

SignsAIの月次サーベイは11問で構成されています。これは Gallup Q12（12問）とは異なる**独自設計**であり、以下の理論的フレームワークを参照しています：

| 参照理論 | 反映している設問領域 |
| :--- | :--- |
| **自己決定理論（Deci & Ryan）** | 自律性・有能感・関係性に関する設問 |
| **JD-Rモデル（Job Demands-Resources）** | 仕事の要求度と資源バランスに関する設問 |
| **心理的安全性（Edmondson）** | 発言・挑戦・失敗の安全性に関する設問 |
| **組織コミットメント（Meyer & Allen）** | 情動的・継続的・規範的コミットメント |

11問という設問数は、回答者の負担（1分以内で完了）と分析の解像度（4領域 × 複数指標）のバランスを取った結果です。Gallup Q12の質問項目とは内容・表現ともに**完全に異なる独自設計**であり、提携・準拠関係はありません。

## 2. SignsAI独自フレームワーク

### 2-1. KPI × 体温 4象限 — 組織ポートフォリオ管理（核心モデル）

**SignsAIの中核となる4象限分析は「KPI達成 × 体温」の組み合わせです。** その他のマトリックス（総人件費×体温、部署別偏差×体温など）は、この核心モデルを補完する **分析レイヤー** として位置づけられます。

| 分析レイヤー | 軸 | 目的 |
| :--- | :--- | :--- |
| **核心モデル** | KPI達成 × 体温 | 組織の健全性と業績の同時評価 |
| コスト視点 | 総人件費 × 体温 | 投資効率の評価 |
| 組織視点 | 部署別偏差 × 体温 | 部署間バランスの評価 |

迷ったときは常に **「KPI達成 × 体温」** の核心モデルに立ち返ってください。

| 象限 | KPI達成 | 体温 | 組織状態 | 推奨アクション |
| :--- | :---: | :---: | :--- | :--- |
| **持続可能な成長** | ✅ | 🔴 高 | 好循環。理想状態 | 成功パターンを横展開 |
| **燃え尽きリスク** | ✅ | 🔵 低 | 数字は出ているが限界が近い | 即座に負荷軽減・対話介入 |
| **潜在力未発揮** | ❌ | 🔴 高 | やる気はあるが成果に繋がっていない | 目標設定・スキルギャップ診断 |
| **構造的課題** | ❌ | 🔵 低 | 機能不全。最優先で対処が必要 | 経営レベルの構造的介入 |

> ※ 4象限の判定は**単月のスナップショットではなく、3ヶ月以上の継続トレンド**で評価することを強く推奨します。特に「燃え尽きリスク」「潜在力未発揮」は単発の数値変動と見分けがつきにくいため、継続性の確認が必須です。
> 
> また、「潜在力未発揮」象限は「やる気はあるが成果に繋がっていない」状態を指しますが、実際の原因は **スキルギャップ・市場要因・構造的障害** など多岐にわたります。原因特定には別途ヒアリングや個別分析が必要です。

### 2-2. 「Gallupの課題」→「SignsAIのアクション」への変換レイヤー

Gallup等のマクロ診断と、従来の人事コンサルティング、そしてSignsAIの役割を以下のように分業・定義します。

| 階層 | 主体 | 役割 | SignsAIの位置づけ |
| :--- | :--- | :--- | :--- |
| **マクロ診断** | Gallup / 学術機関 | 課題の可視化と警鐘 | 理論的根拠の提供 |
| **中長期施策** | 人事コンサル / 研修 | スキルセットの変革 | 介入のヒントの源泉 |
| **運用レイヤー** | **SignsAI** | **日次・月次の意思決定支援** | **現場で「今、何をすべきか」をAIが断言する** |

SignsAIは、マクロな課題意識（Gallup）を、具体的な現場のアクション（AI提言）へと変換する**「ラストワンマイル」を埋めるデータドリブンな意思決定支援ツール**です。

## 3. 引用・運用に関するガイドライン（品質管理）

本思想を外部（ピッチ資料、LP、営業資料等）で運用する際は、以下の原則を遵守してください。

### ✅ 推奨される論法
- 「Gallupが示す世界規模のエンゲージメント低下という課題に対し、現場のアクションレベルで解決策を提供するのがSignsAIである。」
- 「統計的に確認されている『体温とKPIの相関』という構造を、1画面で管理可能にする。」
- 「Balanced Scorecardの思想に基づき、財務指標と感情指標を統合して組織の実態を把握する。」

### ❌ 禁止される論法
- **効果の定量保証の混同**: 「Gallupが9.6兆ドルの損失と言っているから、SignsAIを導入すれば売上が9%上がる」といった、特定ツールの導入効果とマクロな統計データを直接結びつける表現。
- **指標の同一視**: SignsAIのスコアは独自の測定指標であり、GallupのQ12と同一ではない。提携関係を誤認させる表現は厳禁。
- **因果関係の断定**: 「体温が上がれば売上が上がる」という因果表現は避け、「体温が高い組織はKPIが高い傾向がある」という相関表現に留める。

> [!IMPORTANT]
> 上記のガイドラインは、人間が作成する資料だけでなく、**AIが生成するテキスト（aiComment, aiAnalysis等）のプロンプト設計にも適用**されなければなりません。
> 
> **実装ステータス（2026-05時点）：**
> - ✅ 基本プロンプト設計（断定表現の抑制）：実装済み
> - 🚧 禁止フレーズの自動検出フィルタ：**未実装（次フェーズ）**

## 4. 意思決定の指針

今後、新機能の開発やUXの改善において迷いが生じた際は、以下の問いに立ち返ってください。

1. **その機能は、経営層・マネージャーの意思決定コストを下げているか？**（Balanced Scorecardの実用化）
2. **その機能は、KPI（数字）と体温（感情）の相関をより鮮明にしているか？**（2軸統合の原則）
3. **その機能は、問題が顕在化する前の「兆候（Signs）」を捉えているか？**（先行指標の原則）
4. **その機能は、回答者の心理的安全性を損なっていないか？**（Edmondsonの原則）
5. **その機能は、人件費を「コスト」ではなく「投資」として扱っているか？**（Human Capital ROIの原則）

## 5. AI判定の限界とアカウンタビリティ

SignsAIは「AIが今、何をすべきかを断言する」設計を採用していますが、これは**AIに最終決定権を委ねる**ことを意味しません。

### 5-1. AIの位置づけ
- **AIは意思決定支援ツールであり、最終判断は常に人間（経営層・マネージャー）が行う。**
- AIの提言は「**選択肢の整理と優先度の提示**」であり、「**正解の決定**」ではない。

### 5-2. 誤判定時の運用
- AIが明らかに誤った提言を出した場合、ユーザーはダッシュボード上のフィードバック機能（実装予定）から誤りを報告できる。
- 報告された誤判定は、プロンプト改善・データ品質確認の入力として活用される。
- 重大な経営判断（人事・予算・組織再編）については、AI提言を**唯一の根拠としない**ことを明示的に推奨する。

### 5-3. データ品質の前提
- AI診断の精度は、入力データ（KPI・サーベイ回答数・継続期間）の質に依存する。
- 回答者数が少ない期間、データ蓄積が3ヶ月未満の期間は、AI診断の信頼性が低下することを明示する。

## 6. 用語集（Glossary）

| 用語 | 定義 |
| :--- | :--- |
| **体温** | 月次サーベイ（11問・5段階）の平均スコアを指す独自指標。組織のエンゲージメント・コンディションを表す。Gallup の Q12 とは異なる独自設計。 |
| **兆候（Signs）** | KPIに先行して変化が現れるエンゲージメント・体温・コミュニケーションパターン等の先行指標群。プロダクト名の語源。 |
| **断言** | AIによる「今最も注目すべき領域・取るべきアクション」の提示。最終決定権は人間にあり、選択肢の整理を意味する。 |
| **4象限** | KPI達成 × 体温 を軸とした組織ポートフォリオ分析の核心モデル。 |
| **k-匿名性** | 個人を特定不能にするためのプライバシー保護基準。SignsAIでは k=3 を最小閾値として採用。 |
