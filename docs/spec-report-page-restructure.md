# 仕様書：AI組織診断レポート（ダッシュボード report セクション）の整理

> ステータス：設計・仕様（実装前）
> 対象：`src/app/page.tsx`（report セクション）、`src/components/dashboard/ReportSection.tsx` / `MainInsightCard.tsx`（必要に応じ）
> 目的：レポートページの4つの分かりにくさ（注意バナーの重複・全社/タブの誤解・文字サイズ不揃い・文字だけで飽きる）を解消する。

## 現状（コードで確認済み）
- `page.tsx:180` の **注意バナー（anomalyAlert）が全 `sec` ブロックの外側**にあり、どのセクション/タブでも常に表示される。
- report セクションは2層：
  - 上（`220`〜）：タブ（全社/各部署）＋「全体体温」カード（`MainInsightCard`、**タブで内容が変わる**）＋部署選択時の「AI方針翻訳」カード。
  - 下（`359`〜）：`ReportSection`（総評/相関/整合性/リスク/提言）＝ `aiContent.deep_report.*`、**常に全社固定でタブ非依存**。
- → タブ切替で上は変わるが下（本体）は全社のまま＝「タブで全部変わる」と誤解。
- 文字サイズが `text-[10px]/[9px]/[11px]/xs` 混在。

## 変更方針

### ① 注意バナーは1か所だけ（確定）
- anomalyAlert バナーを **report セクション表示時（`sec === 'report'`）にのみ**表示する（AI診断の本拠地に置く）。他セクションでは出さない。
- report 内に置くため「詳細を見る →（report へ遷移）」CTAは不要 → 削除、または「全社レポートへ」アンカーに置換。

### ② 全社レポートを固定し、部署別を別ブロックに分離（確定）
- report セクションを**2つの明確なブロック**に再構成：
  - **A. AI組織診断レポート（全社）**：タブ非依存の主コンテンツ。
    - 全体体温の全社サマリー（`MainInsightCard` の全社版）＋ `ReportSection`（deep_report 5項目）。
    - 見出しで「全社」と明示（例：「AI組織診断レポート（全社）」）。
  - **B. 部署別の診断メッセージ**：別ブロックとして下または横に明確に分離。
    - 見出し「部署別の診断メッセージ」＋**タブ（各部署）をこのブロック内に移動**。
    - 選択部署の `insights_by_dept`（AI方針翻訳）を表示。
- **タブを上部から B ブロック内へ移す**ことで、「タブは部署別メッセージだけを切り替える」と直感的に分かるようにする（A の全社レポートはタブで変わらないことが明確になる）。

### ③ フォントサイズの統一（確定）
- report セクション内の本文・見出しのサイズを統一スケールに：
  - セクション見出し＝`text-sm font-black`、サブ＝`text-[10px] uppercase`、本文＝`text-sm`（または `text-xs` のいずれかに統一）。
  - `text-[9px]/[10px]/[11px]` の混在をやめ、本文は1サイズに揃える。

### ④ 冒頭にキー指標サマリーを追加（確定・配色は落ち着いたトーン）
- 全社レポート（A）の**冒頭に「キー指標サマリー」**を追加。文章の前に結論が見えるように。
  - 指標例：**全体体温**（X.X / 5）、**主要KPI達成率**（X%）、**リスクレベル**（低/中/高）。データは既存の survey/KPI/`aiContent.risk_level` から。
  - 表示：アイコン＋小チップ。**配色はチカチカさせない**＝彩度低めの落ち着いたトーン（白/極薄背景＋細い枠 or 小さな状態ドット）。リスクレベルのみ控えめな色（低=slate/teal寄り、中=amber寄り、高=rose寄り）を**淡く**。面で強く塗らない。
- `ReportSection` は既に各項目アイコンあり → 活かす。必要なら区切り・余白を整える。

## レビュー観点（Claude）
- 注意バナーが report 以外で出ていないか。report で重複していないか。
- 全社レポート（A）が**タブで変わらない**こと・部署別（B）だけがタブで変わることが視覚的に明確か。
- `insights_by_dept`（部署別メッセージ）と deep_report（全社）のハンドラ/データが移動で壊れていないか。
- フォントサイズが統一されているか（`text-[9px]` 等の散在解消）。
- キー指標サマリーの配色がチカチカしていないか（彩度低め・面塗り回避）。リスクレベルの色分けが既存の落ち着いた方針と整合。
- マネージャー時の初期タブ（自部署）・ロール出し分けが壊れていないか。
